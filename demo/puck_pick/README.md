# puck_pick demo

선반(7 cm) 위 퍽을 집어 clock 12번 슬롯에 적재(`sis1`)하고, 다시 꺼내 앞에 내려놓는(`sis2`) 실물 데모.
planning을 거치지 않고 `/planning/task_command`로 control_master에 직접 단계별 명령을 보낸다.

    ~/craft/demo/puck_pick/show.sh                          # RViz 미리보기 (하드웨어 없음)
    python3 demo/puck_pick/plan.py                          # IK 계획 -> plan.yaml
    bro   # 터미널 A: 보드 확인 + control
    sis1  # 터미널 B: 집어서 적재   (execute.py, --dry-run: 단계만 출력)
    sis2  # 터미널 B: 꺼내서 내려놓기 (execute.py --unload)
    sis3 N        # 터미널 B: 주사위 N(1-6) 만들기, 단계마다 Enter (execute.py --dice N)
    sis3 N choi   # 한 번에 끝까지 (Enter 없이, Ctrl+C = STOP + hold)
    teacharm      # 자세 jog / 저장 (teach.py, control_master 끈 상태)

가정값은 `plan.py` 상단 `ASSUME`. 실행 방법, 잡기 좋은 영역, 트러블슈팅, 변경 기록은 [NOTES.md](NOTES.md).

## 주사위 데모 (`sis3`, 2026-11-07)

clock에 적재된 퍽을 하나씩 꺼내 박스(205×205×70 mm) 위에 주사위 눈 N개 모양으로 세웁니다.

**배치**
- 박스 앞 모서리는 LiDAR 앞면에서 10 mm 앞입니다. 박스 중심은 LiDAR 중심에서 LM 모터 쪽으로 2.8 mm(`DICE_BOX_X_MM`)에 둡니다.
  그래서 박스 왼쪽 모서리는 LiDAR 중심에서 왼쪽 99.7 mm, 오른쪽 모서리는 오른쪽 105.3 mm입니다.
  이 2.8 mm는 오차 수식(아래)을 넣었을 때 LM 양끝에서 퍽이 실제로 놓이는 범위(−46.0 ~ +51.7 mm)의 가운데입니다.
  이전 위치: LM 가운데(+12.65), 12시 칸 정렬선(+7.5, LM 548.3°).
- 3×3 격자는 60 mm 간격이고 줄은 LiDAR 앞면에서 172.5 / 112.5 / 52.5 mm입니다.
  박스 윗면 표시(박스 앞-왼쪽 모서리 원점, x = 모터 쪽, y = 앞): x 42.5 / 102.5 / 162.5, y 42.5 / 102.5 / 162.5.
- 양옆 열은 격자점까지 LM이 닿지 않아 LM 끝에 놓입니다. 수식으로는 양쪽 다 격자점에서 안쪽으로 약 11.1 mm 떨어집니다.
  허용 오차 10 mm를 1.1 mm 넘습니다. 가운데 열은 격자점에 맞습니다.
- 눈 모양은 `DICE_FACES`(위쪽 줄 = 먼 줄)이고, 2와 3은 먼-왼 / 가까운-오 대각선입니다. clock 슬롯 순서는 `DICE_SLOTS` [12, 1, 2, ...]입니다.

**퍽 하나의 순서와 단계별 설정** (`execute.py` `dice_steps`)

| 단계 | 허용오차 | I 게인 숄더/엘보/손목/툴롤 | 이동 시간 |
| --- | --- | --- | --- |
| clock을 다음 슬롯으로 | – | – | – |
| via (노미널 경유점) | 3° | 기본 130/100/200/100 | 상한 |
| 퍽 위 40 mm (손목 +1.5°, 그리퍼 94° 완전 개방) | 0.5° | 기본 | 상한 |
| 집기 하강 → 닫기 | 0.5° | 기본 | 상한 |
| 집고 상승 40 mm (한 번에) | 0.5° | 숄더 100 | 상한 |
| via (퍽 들고) | 3° | 기본 | 상한 |
| 칸 위 75 mm (툴롤 0) | 0.5° | 기본 | 상한 |
| 내려놓기 (한 번에, **닿으면 멈춤**) | 0.5° | 130/80/160/100 | **2 s** |
| 그리퍼 완전 개방 | – | – | – |
| 놓고 상승 75 mm (한 번에) | 3° | 130/80/160/100 | 상한 |
| 끝: 노미널 | 0.5° | 기본 | 상한 |
| 끝: 노미널 그대로, 숄더 I 0 (움직임 없음, 기다리는 동안 숄더가 데워지지 않게) | 3° | **0**/100/200/100 | – |

- 닿으면 멈춤(`STEP_CONTACT`, 2026-11-07): 내려놓기 중에 숄더 전류가 이동 중간값의 70% 밑으로(2번 연속; 처음 40%는 7~10 mm 더 눌렀음) 떨어지거나, 이동 끝 무렵 관절이 멈추면
  control_master가 그 자리를 목표로 바꾸고 단계를 성공으로 끝냅니다(결과 이유 `contact (...)`). 1343/1451에서 far 퍽이 목표보다 10~18 mm 위에서
  박스에 닿은 뒤 그리퍼가 박스를 누르던 문제 때문입니다. bag 재생: 0455/1237/1246 거짓 감지 없음, 1343/1451 1.67~1.87 s에 감지.
- 이 값을 정하는 상수: `LOOSE_STEPS` / `VIA_TOLERANCE_DEG`(허용오차), `STEP_I_GAINS` / `I_GAINS_BASE`(게인; 기본값은 펌웨어
  `kPositionIGains`와 같아야 함), `STEP_SECONDS`(이동 시간; 단계 이름 안의 키로 찾음), `DICE_ROWS`(줄별 자세).
  이 값들은 TaskCommand의 `tolerance_rad` / `position_i_gains` / `duration_s`로 control_master에 전달됩니다(`src/craft_control/README.md`).
- 놓는 위치 오차 수식(2026-11-07 `sis3 6 choi`, 퍽 6개, 박스 위에서 실측).
  x = LM 모터 쪽, y = LM에서 먼 쪽(mm)이고, 기준은 퍽을 겨눈 자리입니다. xc = 겨눈 퍽 중심(LiDAR 중심에서 모터 쪽),
  t = (줄의 앞쪽 거리 − 112.5) / 60입니다(near −1, middle 0, far +1).

      ex = −9.83 − 0.0298 (xc − 12.65)      LM 반대 끝 −8.3, 모터 끝 −11.3. 줄에 따른 차이 없음. 잔차 RMS 0.9
      ey = 10.5 + 2.75 t − 6.75 t²          near +1.0, middle +10.5, far +6.5. 열에 따른 차이 없음. 잔차 RMS 0.7

  ex는 LM 목표에 반영합니다(`DICE_EX_MM`, `dice_lm`: 겨눌 곳 + ex = 격자점). ey는 줄 자세 `DICE_ROWS`에 한 번 반영했습니다
  (URDF 모델에서 높이와 툴 각도를 유지한 채 ey만큼 로봇 쪽으로). 잔차 1 mm 안팎은 박스 굴곡과 놓을 때 퍽이 밀리는 정도입니다.
  다시 잴 때는 `sis3 cal away|mid|motor`를 씁니다. 그 LM 위치(142.0 / 594.1 / 1046.2°)에 ex 보정 없이 far, middle, near 순서로 퍽 3개를 놓습니다.
  열 사이가 50 mm라 퍽이 겹치므로 한 열씩 돌립니다.
- 줄별 높이: 처음에는 가운데 줄만 딱 맞았고, 가까운 줄은 2 mm 떠서 떨어지고 먼 줄은 3 mm 파고들었습니다.
  그래서 먼 줄 내려놓기 자세를 +5 mm, 가까운 줄을 −2 mm 옮겼습니다(툴 각도와 수직선은 유지).
  모델의 절대 높이는 실물과 약 17 mm 어긋나므로 높이는 손으로 맞춘 접촉 자세에서 상대적으로만 옮깁니다.
