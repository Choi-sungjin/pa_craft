# 2026-11-13 팔·카메라·강화학습 작업 정리

## 요약

- 어퍼캠으로 서 있는 퍽을 찾아 IK로 집고 캐러셀에 넣는 흐름(`bigbro`)이 실물에서 3번 성공했다. 퍽 2개 연속(`bigbro2`, 12시 → 11시)은 첫 퍽까지만 성공했다.
- 팔 nominal·via 자세를 새로 정했다. 이동은 시간 기반으로 부드럽게 바꿨다.
- R1 잔차 강화학습 정책은 실물에 연결하지 않았다. 가상 실행에서 퍽 yaw에 따라 보정값이 포화되어 멈추고, pa22 측도 서 있는 퍽은 IK 유지를 권했다.
- 손목 4번 모터가 팔을 멀리 뻗은 자세에서 반복해서 끊겼다. 모터 전원도 10.2~10.9 V까지 처진다. 하드웨어 점검이 다음 작업의 전제다.
- 그립캠(손목 D435) 퍽 인식은 안정적이다(20/20, 흔들림 0.04 mm). 그립캠과 어퍼캠 좌표를 맞추는 핸드아이 보정은 기준판이 없어 실패했다.

## 1. 팔 자세와 이동

| 항목 | 값 (raw 모터 도: LM, shoulder, elbow, wrist_pitch, tool_roll, gripper) |
|---|---|
| nominal | 561.4, 53.9, 178.0, 58.4, 0.0, 73.1 |
| via | 561.4, 93.3, 177.6, 61.3, -0.4, 73.1 |
| carry via (퍽 들고 클락에서 나올 때) | via LM, 92.5, 182.9, 104.6, 90.0, 141.9 (11-06 via) |

- 이동 속도: nominal로 들어가는 이동과 via로 가는 이동은 5.2°/s 시간 기반이다. nominal로 들어갈 때는 마지막 4°를 1.5°/s로 따로 간다. 작업 단계는 원래 속도다.
- 경로 규칙: 작업 → via → nominal 순서로 복귀한다. 퍽을 들고 클락에서 나올 때는 shoulder를 5° 바깥으로 갔다가 carry via로 간다. 퍽 끝이 거치대(그리퍼가 nominal에서 걸치는 구조물, 배터리 위 65 mm)에 닿았던 문제를 이렇게 피한다.
- 시작 검사: LM이 nominal에서 10 mm를 넘으면 시작하지 않는다. 전원이 끊긴 뒤처럼 필요하면 `--lm-tol-mm 15`로 한 번만 넓힌다.

## 2. 퍽 집어 넣기 (`bigbro`, `bigbro2`)

| 명령 | 하는 일 |
|---|---|
| `bigbro [--plan plan_cam.yaml] [--slot N] [--no-home]` | via → 퍽 위 40 mm → 그립캠 확인 → 내려가 잡기 → 들기 → 손목 접기 → 클락 칸 → sis2 슬롯 자세로 넣기 → carry via → via → nominal |
| `bigbro2` | 퍽 2개를 12시, 11시 칸에 차례로. 퍽마다 어퍼캠으로 한 번 찍어 가까운 퍽부터 집는다 |
| `demo/puck_pick/cam_pick.py --capture` | 어퍼캠 퍽 위치 → `plan.py` IK → `plan_cam.yaml`. 퍽 윗면 높이로 받침 높이를 정하고 윗면에서 45 mm를 잡는다. 다른 퍽이 80 mm 안이면 멈춘다 |

- 기존 sis1 적재 자세(11-03 손으로 맞춤)는 클락 재조립 뒤 12시 칸에서 36 mm 어긋나 쓰지 않는다. `bigbro`는 sis2의 슬롯 자세(11-06)를 쓴다.
- 클락은 칸 번호로 돌아간다. 12시와 1시 정렬을 실물로 확인했다. 11시 칸 넣기는 아직 실물 미확인이다.
- 어퍼캠 좌표: V307 URDF의 컬러 렌즈 y가 반대로 들어가 있어 +32.2 mm로 고쳤다. 좌우 부호(`LATERAL_SIGN` +1)는 실물 집기 2번과 그립캠 사진으로 확인했다. 실제 잡은 위치는 카메라 퍽 위치보다 x로 약 15 mm 짧았다.

### 실물 결과

| 시각 | 퍽 (어퍼캠 x, y mm) | 결과 |
|---|---|---|
| 20:0x | 사각 345, -1 | 집기 성공. sis1 적재 자세로 넣다가 칸에 안 들어감, 복귀 중 거치대 충돌로 수동 정지 |
| 20:3x | 사각 319, -41 | `bigbro` 전 단계 성공, 12시 칸에 들어감 |

| 20:57 | 원기둥 392, +31 (2개 중 2) | 퍽 위로 가는 중 4번 모터 끊김 |

깊이 문제는 받침 실측(72~74 mm)과 얕은 잡기(45 mm)로 고쳤다. 실물 재확인은 아직이다. 퍽을 넘어뜨린 원인은 확정하지 못했다.

## 3. 그립캠 확인 단계

- `bigbro`에서 퍽 위 40 mm에 선 뒤, 그립캠으로 퍽을 찾아 정렬 기준과 비교한다. 10 mm 넘게 어긋나면 내려가지 않고 멈춘다(`tools/realsense_check/grip_locate.py`).
- 성능(원기둥, 팔 정지): 20장 중 20장 인식, 위치 표준편차 0.04 mm, 깊이 182 mm.
- 한계: 기준 사진은 사각 퍽이 오른쪽 집게에 조금 치우친 상태로 찍은 것이다. 원기둥과는 +15 / -9.5 mm 차이가 났다. 퍽을 집게 정가운데에 둔 상태로 기준을 다시 찍어야 한다. 어긋난 만큼 자동 보정하는 기능은 없다(카메라 축과 팔 축의 관계를 아직 모름).

## 4. 강화학습(R1 잔차 정책)

- 팩: `~/rl_packs/standing_puck_robot_pack`. 가상 실행: `demo/puck_pick/rl_shadow.py`.
- 좌표: 팩(V311)과 어퍼캠(V307 base_link)은 같은 배치다. 우리 관절(V75)을 V311로 바꾸는 변환을 FK로 맞췄다(TCP RMS 5.7 mm). LM 원점은 실물 집기 자세로 맞췄다.
- pa22 답 반영: 학습 박스 윗면은 70 mm인데 팩은 90 mm로 가정했다(`puck_clear` 수정함). 방해 퍽은 학습 때 항상 박스 위에 있었다. 실물 TCP는 목표를 늦게 따라온다.
- 가상 결과(반영 후): 우리 퍽 위치에서 yaw 0.05~0.6이면 끝까지 집었고, yaw 0, 1.2, -0.6이면 처음부터 보정값이 100% 포화되어 멈췄다. 들어 올린 뒤(LIFT·HOLD)는 늘 100% 포화다. 잔차를 끄면(β = 0) 모든 위치에서 집는다.
- 판단: 서 있는 퍽은 IK(`bigbro`)를 유지한다. 실물 오차(카메라-팔 고정 오차, 받침 높이)는 정책 관측에 드러나지 않아 잔차 보정으로 고쳐지지 않는다. 쓰려면 그립캠으로 본 퍽-집게 상대 위치를 관측에 넣어야 한다.
- 전달 문서: `~/rl_packs/real_robot_report_20261113.md`, Claude Docs "R1 잔차 정책 실물 연결 검토".

## 5. 모터와 전원

자세한 내용은 `demo/puck_pick/motor4_load_report_20261113.md`.

- 원기둥 먼 자세(LiDAR 앞 182 mm)에서 손목 4번이 약 1 A, 어깨 2번이 0.85 A를 계속 썼다(bag `~/bags/gripcam_1113_2124`). 4번은 버티기 시작한 지 7초 뒤 끊겼다. 온도는 31 °C였다.
- 4번이 끊겨도 5·6번은 응답했다. 배선보다 4번 모터 자체를 먼저 의심한다.
- 4번이 끊긴 뒤 팔 보드를 다시 올리면 모터 6개가 다 안 보인다. 팔 12 V를 껐다 켜야 돌아온다.
- 모터 전원은 움직일 때 10.2~10.9 V까지 처지고, 휠 모터도 가끔 끊긴다.
- 당분간 퍽은 LiDAR 앞 150 mm 안쪽에 둔다.

## 6. 핸드아이 보정 (실패)

- 도구: `tools/realsense_check/handeye.py` (capture / reprocess / solve). V75 → V307 관절 변환은 `v75_to_v307.json`(TCP RMS 8.3 mm).
- 자세 3개, 태그 점 6개로 풀었으나 오차 191 mm로 쓸 수 없다.
- 원인: 퍽 태그 번호는 퍽마다 하나라 여러 면에 같은 번호가 있다. 두 카메라가 같은 번호의 다른 면을 보면 다른 점이 같은 점으로 짝지어진다.
- 다음: 퍽에 없는 번호(예: 20번)의 tag36h11을 6~8 cm로 인쇄해 책상에 붙이고, 꼭짓점 4개를 점으로 써서 shoulder·LM·높이를 바꾼 자세 6개로 다시 한다. 이 기준판으로 관절 변환이 손목 방향까지 맞는지도 검사한다.

## 7. 남은 일

1. 손목 4번 모터 점검: Wizard로 에러 상태·전압·전류 제한 확인, 다른 XM430으로 교체 시험, 원기둥 자세에서 4번 커넥터 전압 측정.
2. 12 V 전원 점검: 배터리 상태와 커넥터, 가능하면 5 A 이상 파워서플라이로 같은 동작 시험.
3. 그립캠 정렬 기준을 집게 정가운데에서 다시 찍기. LM을 정해진 만큼 움직여 카메라 축과 팔 축의 관계를 구하고, 어긋남을 자동 보정.
4. `bigbro2` 고치기: via에서는 팔이 어퍼캠을 가리므로 다음 퍽을 찍을 때는 nominal로 간다.
5. 11시 칸 넣기 실물 확인, 퍽을 넘어뜨린 원인 확인(다음 실행부터 `armbag` 녹화).
6. 핸드아이 보정을 인쇄 태그로 다시 하기.
