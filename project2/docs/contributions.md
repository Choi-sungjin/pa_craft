# 개인별 기여 정리 — A팀 크래프트

사용자가 제공한 [팀 노션](https://www.notion.so/82819e206c8083d7ba8c012bbfd6ee5f)의 개인 일지 87개 항목과 팀원 소개를 2026-11-17에 확인함. 연결된 MCP는 404를 반환했으나 공유된 공개 페이지의 읽기 요청으로 내용 확인에 성공함. 작성자가 있는 항목은 83개, 없는 항목은 4개임. 전체 제목·작성일·작성자·상태·원문 링크는 [개인 일지 색인](contribution-journals.csv), 조회 범위와 이름 대응은 [출처 기록](contribution-sources.json)에 수록함.

계정 표시 이름은 사용자 확인에 따라 **준명=박준명, 규진 심=심규진, 성진 최=최성진, 여훈 마=한지훈**으로 통일함. 공동 작성 일지를 한 사람의 단독 구현으로 바꾸지 않음. 아래 수치와 수행 내용은 별도 표기가 없으면 **일지에 기록된 결과**이며 이번 정리에서 다시 실험한 결과가 아님. 일지의 ‘완료’ 상태가 전체 프로젝트 완료를 의미하지 않음.

**검증 근거:** 신호 보강 전후 관찰, 공동 회전·도킹 시험이 있음. ‘완료’로 표시된 일지라도 본문에 남은 TODO나 미검증이 있으면 완료 증빙으로 확대하지 않음.

**리뷰 근거:** 공동 작성은 확인되지만 이것만으로 동료 PR 리뷰를 수행했다고 판단하지 않음. 구체적인 리뷰·수정 반영 링크가 필요함.

**설명 근거:** [인지 시나리오](https://www.notion.so/50119e206c80828b813701fbc3271b8f), 제어 시나리오와 인지 모듈 설명이 있음. 전체 시스템을 직접 설명한 자료는 별도로 연결해야 함.

## 제출 근거의 완료 여부

개인 일지로 **누가 어떤 문제를 다뤘고 무엇을 남겼는지**는 정리되었음. 개인 평가의 구현·검증·리뷰·설명 각 5점은 자동 채점하지 않음. 각자 의미 있는 병합 PR, 자신의 시험 원본·조건·코드 버전, 동료 PR 리뷰와 반영 확인, 팀 전체 시스템 설명 자료를 연결해야 함. 외부 Drive·이전 브랜치·첨부 영상의 현재 접근 가능성까지 모두 재검증한 것은 아니며, 공개 노션 요약과 확인된 저장소 근거를 구분하여 제출함.
