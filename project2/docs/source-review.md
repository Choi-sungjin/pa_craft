## 의미가 다른 완료 상태

문제 풀이 가능성은 할당 계산으로 확인함. 빌드 성공은 실행파일 생성 근거임. 집기 로그의 완료는 실행 단계 결과임. 공식 경기 성공은 실제 정답 배치·새 관측·복귀 및 채점 근거가 있어야 함. 네 상태를 하나의 ‘구축 완료’로 묶지 않음.
