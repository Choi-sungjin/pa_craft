# 문제 패키지 — 공개 연습 문제 Q1

이 폴더는 제공된 Q1을 재현하고 계산으로 검증한 **공개 예제 패키지**임. 실제 팀 제출 문제의 확정 기록은 아직 없음. 경기 규칙·평가는 [mission.pdf](reference/mission.pdf), 프로젝트 목적·제출 범위는 [launch.pdf](reference/launch.pdf)를 기준으로 함.

## 입력과 초기 배치

신호는 `RGRRGRGGYGYG` 12회, 횟수는 R4·Y2·G6, 바코드는 Code128 `P2-01`임. [signals.json](signals.json)에 순서·횟수·시간 조건을 기록함. [placement.csv](placement.csv)는 퍽 12개의 ID·색상·모양·시작 박스·좌표를 기록한 표임. 원래 제공된 혼합 배치 표는 [field-layout.csv](field-layout.csv)에 보존함. 벽과 기둥은 [walls.csv](walls.csv), [posts.csv](posts.csv)를 따름.

미로 전체는 4464×6364 mm이며 기존 벽·기둥·박스는 이동하지 않음. 좌표 원점은 좌하단 기준 기둥 중심, +Y는 도면 위쪽, 바닥 Z=0임. 시작 박스는 205×205×70 mm이며 각 박스 중심 X±40 mm, Y=0에 퍽을 2개씩 놓음. 퍽 바닥 높이는 70 mm, 윗면은 130 mm임. L1~L3는 비워 둠.

| 장소 | 중심 X, Y (mm) | 역할 |
| --- | --- | --- |
| S1 | 1468, 950 | 시작 퍽 2개 |
| S2 | 3670, 3152 | 시작 퍽 2개 |
| S3 | 2936, 5354 | 시작 퍽 2개 |
| S4 | 734, 5354 | 시작 퍽 2개 |
| S5 | 2202, 5354 | 시작 퍽 2개 |
| S6 | 3670, 3886 | 시작 퍽 2개 |
| L1 / 태그 12 | 3670, 950 | 주사위 격자 중심 |
| L2 / 태그 13 | 2202, 3700 | 중앙 받침대 북쪽 격자 중심 |
| L3 / 태그 14 | 3670, 5354 | 주사위 격자 중심 |

신호등은 본체 하단이 (80,950,0) mm에서 바닥에 닿도록 세로로 설치하고 +X를 향하게 함. 발광면 높이는 실물 기준이며 바닥 Z=0을 렌즈 높이로 해석하지 않음. 바코드 중심은 (80,650,450) mm, +X 방향임. 관측 기준 위치는 (734,950) mm, 시선은 −X임.

## 신호·바코드 해석

R/Y/G는 각각 1~6회이고 합은 12회임. 점등 1초·소등 1초를 사용하며 12회 이후 연속 소등 3초로 종료를 판정함. 별도의 초록 시작 신호를 추가하지 않으며 누락된 색을 정답으로 추정하지 않음. 신호 종료 및 바코드 해석을 모두 확인한 뒤 출발함.

`P2-01`·`P2-03`은 횟수 오름차순, `P2-02`·`P2-04`는 내림차순임. 동률은 두 방향 모두 R→Y→G 순서임. 정렬 대상은 그룹이며 퍽 ID가 아님. Q1 결과는 **L1=Y2, L2=R4, L3=G6**임.

## 전체 할당과 정답

R은 빨간 퍽만, G는 초록 퍽만 사용하며 모양 혼합이 가능함. Y는 색상 혼합이 가능하지만 모두 같은 모양이어야 함. 노란 퍽은 없음. 12개를 중복·누락 없이 정확히 한 번씩 사용해야 하므로 전체 할당 가능성을 먼저 검사함. ID 0~11에 색상을 영구 고정하지 않음. 이 예제의 빨강 6·초록 6 비율도 경기 고정 조건이 아님.

| 목적지 | 그룹·개수 | 정답 퍽 ID | 조건 |
| --- | --- | --- | --- |
| L1 | Y / 2 | 0, 1 | 모두 원기둥 |
| L2 | R / 4 | 2, 3, 8, 9 | 모두 빨강 |
| L3 | G / 6 | 4, 5, 6, 7, 10, 11 | 모두 초록 |

주사위 격자의 중심 간격은 60 mm이며 축 방향은 맵과 동일함. [answer.json](answer.json), [answer.csv](answer.csv)에 각 ID의 격자 인덱스·중심 상대 좌표·맵 절대 좌표를 수록함. Z는 퍽 바닥 높이이며 TCP 목표가 아님. 실물 목표는 실제 장치 보정과 좌표 변환을 거쳐야 함.

주사위 눈은 지정 방향·개수를 만족하고 중심 오차 ≤10 mm, 안정 상태 2초를 충족해야 함. 사용하지 않는 격자에 추가 퍽이 없어야 하며 쌓기와 바닥 임시 적재를 하지 않음. 세 장소를 새 센서 관측으로 재검증하고 전체 ID의 중복·누락을 판정한 후, 차체 전체가 출발 구역 안에서 3초 정지하면 복귀 조건을 만족함.

## 경기 원점수 100점

| 항목 | 배점 | 판정 |
| --- | ---: | --- |
| 신호 순서 | 12 | 12개 시점별 일치 각 1점 |
| 색상별 횟수 | 9 | R/Y/G 정답 각 3점 |
| 바코드 | 4 | 코드와 정렬 방향 일치 |
| 장소 그룹 배정 | 9 | L1~L3 각 3점 |
| 색상·모양 선택 | 18 | 장소별 개수와 조건 충족 각 6점 |
| 주사위 눈 배치 | 30 | 장소별 눈·위치·안정 조건 각 10점 |
| 새 관측 검증 | 8 | 장소별 ID·위치 각 2점 + 전체 중복·누락 판정 2점 |
| 복귀 | 10 | 차체 전체가 출발 구역 안에서 3초 정지 |

공식 2회 중 높은 **한 회차 전체 점수**를 사용함. 회차별 성공 항목을 섞지 않음. 시간 제한·시간 가산점은 없음. 프로젝트 종합 평가 100점은 별도 구조이며, 통합 경기 25점은 경기 원점수×0.20 + 자율 완주 5점임. 자율 완주는 신호·정렬·세 장소 정답·새 관측 검증·복귀가 모두 성공해야 인정함.

## 운영·오류 처리·검토

운영자는 시작 전 배치표로 12개 속성과 위치, 빈 목적지, 신호·바코드를 확인하고 정답 검증을 실행함. 각 회차는 원래 초기 배치에서 독립적으로 시작하며 영상·로그·코드 버전·설정·운영자 정답을 따로 보관함.

12회 미만/초과, 불명 색상, 미등록 바코드, ID 중복·누락 시 오류를 기록하고 안전 정지함. 팀 오류에 대해 신호를 다시 제시하거나 수동 수정 후 같은 회차를 이어가지 않음. 운영 장비 오류는 무효 처리 후 같은 조건으로 재시도함. 중단 시 그때까지의 유효 점수와 근거를 남김.

계산 검증은 [validation.md](validation.md), 결과는 [validation.json](validation.json)임. [다른 팀 검토 기록](peer-review.md)은 미수행 상태임. 다른 팀 검토와 팀 문제 확정 전에는 문제 제출 완료로 판정하거나 `project2-problem-submit` 태그를 생성하지 않음.
