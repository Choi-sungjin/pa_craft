# 공식 2회차 — 미확인

이 폴더는 공식 경기 증빙이 아직 없다는 상태 기록임. 빈 값을 실제 관측값이나 0점으로 해석하지 않음. 개발 시험과 Q1 정답을 이 회차의 결과로 복사하지 않았음.

`run.json`은 회차·코드·영상·로그·완주·반영 점수 상태, `signal.json`은 실제 신호 관측, `allocation.json`은 12개 퍽 계획, `verification.json`은 배치 후 새 관측을 기록할 위치임. 현재 모두 미확인임. `scorecard.csv`의 최대 점수 합은 100이며 획득 점수는 비어 있음.

실제 회차 자료가 확보되면 운영자 정답, 장비·설정·커밋, 전체 영상·로그, 실패 지점과 항목별 점수를 연결해야 함. 통합 경기 반영 점수는 원점수×0.20 + 자율 완주 5점이며 공식 두 회차 중 높은 한 회차 전체 결과를 사용함.
