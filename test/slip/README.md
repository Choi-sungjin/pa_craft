# 바퀴 슬립 실험

바닥에 1 m를 표시하고, 휠 오도메트리가 1.000 m가 될 때까지 직진한 뒤 실제 이동 거리를 줄자로 잰다.
**사다리꼴 속도 프로파일의 기울기(가속도)만** 바꿔 가며 미끄러지는 정도를 본다. 일반 주행(고속)과
수정 주차(저속) 두 속도를 모두 본다.

## 원리

- `slip_test.py`가 바퀴 OpenCR에 control_master와 **같은 형식**으로 직접 명령한다:
  `wheel_l,wheel_r,clock\n`(소수 4자리, 바퀴 출력축 rad/s, clock은 시작 각도 유지), 50 Hz.
  planning 경로의 속도는 쓰지 않고, 정해진 순항 속도까지 간다.
- 오도메트리도 `WheelOdometry`와 같다. 매 주기 가장 최근 바퀴 속도 피드백을 호스트 시간 간격으로 적분한다.
- 프로파일: `v = min(순항, a·t, √(2·a·남은거리))`. 남은 거리는 오도메트리 기준이라 오도메트리가 1.000 m에서
  멈춘다(끝 몇 mm는 0.01 m/s로 기어감). 멈춘 뒤 0.5 s 정지를 확인할 때까지 계속 적분한다.
- 순항 속도: **고속 = `max_wheel` × 반지름 = 7.8 × 0.033 = 0.257 m/s**(모터 최대), **저속 = 0.05 m/s**.
- 슬립 = 기준 회차 대비 1 m당 잃은 거리(mm/m). 기준(저속, 0.05 m/s²)의 줄자/오도메트리 비율로
  **실제 유효 반지름**을 구해 반지름 오차와 적분 오차를 함께 상쇄한다.

## 조건

| 순항 | 기울기 [m/s²] | 횟수 |
| --- | --- | --- |
| 저속 0.05 m/s | **0.05 (기준)** | 5 |
| 저속 0.05 m/s | 0.1, 0.2, 0.4, 0.8 | 각 3 |
| 고속 0.257 m/s | 0.05, 0.1, 0.2, 0.4, 0.8 | 각 3 |

총 32회(기준 5회 먼저, 나머지는 `slip plan`이 섞은 순서). 0.1 m/s²는 예전 펌웨어 값(0.124)과 비슷하다.
고속 0.05 m/s²만 예외로, 가속·감속에 각 0.66 m가 필요해 1 m 안에서 순항 속도에 못 닿는다
(정점 √(a·1 m) = 0.224 m/s인 삼각형 프로파일). 나머지는 모두 순항 구간이 있다.

## 준비

1. **펌웨어**: 바퀴 Profile Acceleration을 상한 역할만 하게 200(약 2.47 m/s²)으로 올렸다
   (`firmware/wheel_clock/config.h`, 예전 10 = 0.124 m/s²). 로봇을 가만히 두고 `resetwheel` 한 번.
   실험 뒤 주행용 값을 다시 넣는다. 그동안 control로 주행하면 가속 제한이 거의 없다.
2. control_master는 **끈다**(`slip`은 포트가 사용 중이면 거부, 보드 잠금 사용).
3. 바닥: 출발선과 1 m 선. 로봇 옆에 **바퀴 축 중심 위치**를 표시해 기준점으로 쓴다.
   앞으로 1.5 m 이상 비운다.
4. 통제: 같은 바닥 구간, 같은 방향, 같은 출발 자세. 팔은 접은 자세, 퍽 없음. 시작·끝 배터리 전압 기록.

## 실행

```bash
checkwheel                           # 상태 0, imu_ok 1
slip plan                            # 실행 순서
slip run --speed low --accel 0.05    # Enter로 출발, Ctrl+C 정지
# 멈추면: 출발선 -> 기준점 거리(mm), 옆 이탈(mm, + 왼쪽, 생략 가능)을 입력. Enter만 치면 그 회차 버림
slip summary                         # 조건별 슬립 mm/m, 표준편차, IMU yaw, 옆 이탈
```

- 회차마다 `logs/<시각>_<속도>_<기울기>.csv`(명령 속도, 바퀴 속도, 오도메트리, yaw)를 남기고,
  줄자 값을 넣은 회차만 `results.csv`에 쌓는다.
- 보드 fault, 피드백 끊김, Ctrl+C, 30 s 초과 회차는 결과에 넣지 않는다.

## 해석

- 슬립(+) = 바퀴가 실제보다 더 돌았다(헛돎). 가속·감속 구간에서 생긴다.
- 좌우 바퀴 슬립이 다르면 IMU yaw와 옆 이탈이 커진다. 바퀴 yaw(오도메트리)는 그 차이를 모른다.
- 기울기에 따라 슬립이 급격히 늘기 시작하는 지점이 주행용 가속 제한 후보다. 고속(일반 주행)과
  저속(수정 주차) 값을 따로 정할 수 있다.
